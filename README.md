# Candy Auction

Live candy auction site for TMW, ICW and LJW. Hosted on GitHub Pages and timdog85.com, with a Supabase database for live updates.

## Files
- `index.html`, `style.css`, `app.js`: the website
- `config.js`: your Supabase address and publishable key
- `img/`: the candy pictures
- `setup.sql`: creates the database (run once in Supabase)

## Start over
To put all candy back and clear every bid, cooldown and offer, run `setup.sql` again in the Supabase SQL Editor.
